# Sistema de Gerenciamento de Pedidos

Sistema desenvolvido em Java para gerenciamento de pedidos, permitindo o cadastro e controle de clientes, produtos e pedidos diretamente pelo terminal.
O projeto foi criado com foco no aprendizado de Programação Orientada a Objetos (POO), organização de sistemas e manipulação de dados em aplicações Java.

## Estrutura geral do projeto

O projeto é organizado em classes responsáveis pelo gerenciamento das entidades do sistema, como:

* clientes;
* produtos;
* pedidos;
* menus e interação com usuário.

## Funcionalidades

* Cadastro de clientes
* Cadastro de produtos
* Criação de pedidos
* Listagem de informações cadastradas
* Organização dos dados do sistema
* Interação via terminal

## Tecnologias utilizadas

### **Java**

Utilizado para o desenvolvimento completo da aplicação, incluindo:

* lógica do sistema;
* criação das classes;
* gerenciamento de pedidos;
* manipulação dos dados.

### **Git e GitHub**

Utilizados para:

* versionamento do código;
* armazenamento do projeto;
* controle das alterações realizadas.

### **IntelliJ IDEA**

Utilizado como ambiente de desenvolvimento da aplicação.

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/julialm-s/Sistema-de-Gerenciamento-de-Pedidos.git
```

### 2. Acesse a pasta do projeto

```bash
cd Sistema-de-Gerenciamento-de-Pedidos
```

### 3. Compile os arquivos Java

```bash
javac Main.java
```

### 4. Execute o sistema

```bash
java Main
```

O sistema será executado diretamente pelo terminal da IDE.
