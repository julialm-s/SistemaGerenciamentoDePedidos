# 📦 Sistema de Gerenciamento de Pedidos

Sistema desenvolvido em **Java** para gerenciamento de pedidos, permitindo o cadastro e controle de clientes, produtos e pedidos diretamente pelo terminal.

## 📖 Sobre o projeto

O projeto foi criado com foco no aprendizado de **Programação Orientada a Objetos (POO)**, organização de sistemas e manipulação de dados em aplicações Java. Ele simula um sistema real de gerenciamento de pedidos, permitindo cadastrar clientes e produtos, criar pedidos e listar as informações registradas.

---

## 🗂️ Estrutura geral do projeto

O projeto é organizado em classes responsáveis pelo gerenciamento das entidades do sistema:

| Entidade | Responsabilidade |
|---|---|
| 👤 **Clientes** | Cadastro e controle de dados dos clientes |
| 📦 **Produtos** | Cadastro e controle de dados dos produtos |
| 🧾 **Pedidos** | Criação e vínculo entre clientes e produtos |
| 🖥️ **Menus** | Interação com o usuário via terminal |

---

## ⚙️ Funcionalidades

- ✅ Cadastro de clientes
- ✅ Cadastro de produtos
- ✅ Criação de pedidos
- ✅ Listagem de informações cadastradas
- ✅ Organização dos dados do sistema

## 🚀 Como executar

### 1. Clone o repositório
```bash
git clone https://github.com/julialm-s/Sistema-de-Gerenciamento-de-Pedidos.git
```

### 2. Acesse a pasta do projeto
```bash
cd Sistema-de-Gerenciamento-de-Pedidos
```

### 3. Compile os arquivos Java
```bash
javac Main.java
```

### 4. Execute o sistema
```bash
java Main
```

> O sistema será executado diretamente pelo terminal da IDE.
